# AI 使用指南（学生用）

> 一句话：**AI 帮你理解，不替你动手。**
> 你可以让 AI 解释报错、解释概念、指出你代码哪里错、出题考你；
> 不可以让它写你的作业代码、直接给答案。
>
> 这门课的考核是 `grade.py` 判分——飞机要么达标要么不达标，AI 说得再好也伪造不了。
> 所以真正要守住的不是分数，是**你自己的能力**：关掉 AI，你还能不能跑通。

## 一、红绿灯

| 灯 | 可以做什么 | 例子 |
|---|---|---|
| 🟢 **绿灯** | 解释报错原文 · 解释概念 · 出题考你 · 指出你代码的问题（**只指出，不许重写**）· 给排查顺序 · 逐行解释你写的代码 | "这段报错是什么意思？"<br>"我这段代码哪里有问题？只说问题，不要给我新代码。"<br>"就 Offboard 三要素出 3 道判断题考我。" |
| 🟡 **黄灯** | 核对参数名/命令模板/API 签名——**前提是你自己已经从源码查出来了** | "我 grep 到 takeoff_altitude、circle_radius 这几个参数，帮我核对还漏了哪个、单位对不对。" |
| 🔴 **红灯** | 让它生成任务节点 · 让它给完整实现 · 直接要答案 · 整段替换你的代码 | "帮我写一个 hover_node。"<br>"直接给我完整代码。" |

**判断标准很简单**：如果 AI 的输出能直接粘贴交差，那就是红灯；如果它只是让你更明白，那就是绿灯。

## 二、先写后问

不做"先问再做"，做"先做再问"：

1. **先自己写**：写出你的代码、命令或判断，哪怕有错。
2. **再让 AI 只看你的东西**：把**你写的**贴给它，问"哪里错了、为什么"。
3. **自己改**：改完自己跑，跑不通再带着**新的报错**问。
4. **最后讲一遍**：向同学解释这段代码为什么这么写。

禁止的顺序：先问"怎么写"→ 复制 → 跑通 → 交。这样即使通过了，你也没获得能力。

## 三、无 AI 区

以下两类任务**不允许使用 AI**，必须独立完成：

| 任务 | 为什么 |
|---|---|
| 每章的**故障注入卡**（任务卡 3） | 定位故障是核心能力，AI 一说就废掉这次练习 |
| 每章的**最后一张卡** | 综合验收，检验你这章是否真的会了 |

做这两张卡时，把 AI 关掉。卡住可以查本课程的 `faq.md`、看源码、看日志——这些都允许。

## 四、怎么问：给足上下文

本课程锁版本（PX4 v1.15.4 + 17 个补丁），通用答案常不适用。问之前附上：

```text
【课程环境】
PX4 v1.15.4 / ROS2 Humble / Gazebo Harmonic / XTDrone2
命名空间：/x500_0
统一接口：drone_sim.px4_interface.PX4Interface（不要自己 create_publisher 连 PX4）
发布端 QoS：BEST_EFFORT + VOLATILE；订阅端：BEST_EFFORT + TRANSIENT_LOCAL
坐标系：PX4 用 NED（z 向下为正），Gazebo 用 ENU（z 向上为正）

【要求】
只回答我问的问题，不要主动生成实现代码。
不确定的地方请明说"需确认"，不要猜。
```

## 五、怎么验：AI 常错的五处

| 易错点 | AI 可能给 | 本课程实际 |
|---|---|---|
| 消息字段 | `OffboardControlMode.actuator` | 1.15 是 `thrust_and_torque` / `direct_actuator`，**没有 `actuator`** |
| QoS | 默认 RELIABLE | 发布端必须 BEST_EFFORT + VOLATILE，否则死锁 |
| 命名空间 | `/fmu/...` | 用绝对 `/x500_0/fmu/...`，多机还要匹配 `target_system` |
| 坐标 z 符号 | 混用 | PX4 的 `pos.z` 向下为正，接口 `alt()` 向上为正 |
| 命令与版本 | 社区旧教程 | 锁 v1.15.4，以仓库代码为准 |

核对命令：

```bash
grep -vE "^#|^$" ros2_ws/src/px4_msgs/msg/OffboardControlMode.msg   # 字段名
grep -nE "QOS_PUB" ros2_ws/src/drone_sim/drone_sim/px4_interface.py  # QoS 实际配置
python3 tools/grade.py --scenario <场景id> --runs 1                   # 跑通才算
```

## 六、验收：脱稿才算过

一章学完，做这个自检：

1. **关掉 AI**，从零复现本章实验，能跑通并看出判分 PASS。
2. 不看笔记，讲清本章的核心机制（比如"为什么必须先预流"）。
3. 被追问一个"为什么"时，能答上来而不是背结论。

三条都过，才算真的会了。AI 让你更快到达这里，但不该替你走路。
