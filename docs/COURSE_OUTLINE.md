# 课程大纲与知识点覆盖（COURSE_OUTLINE）

> 面向零基础读者的无人机仿真课程大纲。参照三类材料：
> 1. 本仓库实测能力与场景目录（`catalog/scenarios.yaml`、`docs/ROADMAP.md`）
> 2. XTDrone / XTDrone2 教程体系（<https://www.yuque.com/xtdrone/manual_cn>，仓库 <https://github.com/robin-shaun/XTDrone>）
> 3. 教学编写 skill（六段检查清单、任务卡、小白审计、工程文风）

## 一、课程定位与读者假设

| 项 | 内容 |
|---|---|
| 读者 | 会 Linux 命令与 Python 基础；**无 ROS2 / PX4 经验** |
| 技术栈 | PX4 v1.15 · ROS2 Humble · Gazebo Harmonic · XTDrone2 |
| 形式 | 每章 = 原理讲解 + 可复现实验 + 判分指标 + 任务卡 |
| 原则 | 零基础可读（术语首次即解释）、结果可核验（不止"看起来正常"）、诚实标注（实测/未验证） |

## 二、与 XTDrone 教程体系的对照

XTDrone 是按能力模块组织的仿真平台：

| XTDrone 模块 | 内容 | 我们课程对应 | 状态 |
|---|---|---|---|
| `sitl_config` | 仿真环境配置 | 01 环境搭建与首飞 | ✅ 已覆盖 |
| `communication` | 与 PX4 的通信节点 | 02 Offboard 与 PX4Interface | ✅ 已覆盖 |
| `control` | 姿态/位置控制、键盘、精准降落 | 02 / 04 / 06 | ✅ 已覆盖 |
| `sensing/slam` | 视觉与激光 SLAM | 07 激光 SLAM、08 VIO | ✅ 覆盖（VIO 未成功，如实写成研究案例） |
| `sensing/object_detection_and_tracking` | 检测与跟踪 | 05 YOLO、06 精准降落 | ✅ 已覆盖 |
| `sensing/gimbal` | 云台 | — | ⚠️ 模型具备（`gz_x500_gimbal`），未开章节 |
| `motion_planning/2d`、`3d` | 2D/3D 运动规划 | 09 反应式避障 | ⚠️ 自研反应式规划，未用 2D/3D 规划器链路 |
| `coordination/formation_demo` | 编队 | 12 多机编队 | ✅ 已覆盖 |
| `coordination/task_assignment` | 任务分配 | — | ❌ 未覆盖，列为扩展方向 |
| `coordination/fixed_wing_formation_control` | 固定翼编队 | 14 VTOL | ⚠️ 仅单机 VTOL，无固定翼编队 |
| `robocup` / `zhihangcup` | 比赛场景 | — | ❌ 未覆盖（可作为综合项目来源） |

**结论**：我们的课程在"控制—感知—规划—多机"主线上覆盖良好，与 XTDrone 体系同构；差距主要在**云台、任务分配、2D/3D 规划器、比赛综合场景**，列为后续扩展（见第六节）。

## 三、章节结构与每章知识要点

## 四、每章零基础必备的"补白"清单

编写或改写章节时，至少要覆盖以下背景知识（XTDrone 教程默认读者已会，我们要写明）：

- ROS2：节点、话题、消息类型、QoS、参数、launch、命名空间
- PX4：飞行模式（Offboard/POSCTL/RTL）、解锁、EKF、MAVLink 命令
- 坐标：NED / ENU / 机体系 / 光心系，z 符号差异
- 仿真：Gazebo 世界与模型、仿真时间、传感器插件
- 工程：锁版本、补丁、日志限幅、进程与端口
